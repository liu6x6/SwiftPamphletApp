# SVG：可缩放矢量图形

SVG (Scalable Vector Graphics) 是一种基于 **XML** 的、用于描述二维**矢量图形**的开放标准图像格式。与依赖像素的位图格式（如 JPEG, PNG）不同，SVG 使用数学方程式来定义图形中的点、线、曲线和形状。这使得它具有“**分辨率无关**”的革命性特性。

## 核心理念：用代码来绘图

一个 SVG 文件，本质上是一个纯文本的 XML 文件。你可以用任何文本编辑器打开它，并直接阅读和修改其内容。它通过一系列的标签（Tags），来声明性地描述一幅图像。

**一个简单的 SVG 示例**:

```xml
<svg width="100" height="100" xmlns="http://www.w3.org/2000/svg">
  <circle 
    cx="50" 
    cy="50" 
    r="40" 
    stroke="green" 
    stroke-width="4" 
    fill="yellow" />
</svg>
```

这段代码描述了一个：
*   画布大小为 100x100 像素的 SVG 图像。
*   其中包含一个圆形 (`<circle>`)。
*   圆心位于 `(50, 50)`。
*   半径为 `40`。
*   描边（`stroke`）为绿色，宽度为 `4`。
*   填充（`fill`）为黄色。

浏览器或任何支持 SVG 的渲染引擎，在读取这段代码时，都会精确地、可复现地绘制出这个黄色的、带绿色边框的圆形。

## SVG 的主要优势

1.  **可缩放性 (Scalability)**: 这是 SVG 最核心的优势。由于图形是由数学定义，而非像素定义，你可以将一张 SVG 图像，无限地放大或缩小，而它**永远不会失真**或出现马赛克。其边缘始终是清晰、锐利的。这使得它非常适合用于需要适应不同屏幕尺寸和分辨率的响应式设计（如 Logo, 图标）。

2.  **文件体积小**: 对于简单的图形（如 Logo, 图标, 图表），SVG 的文件体积，通常远小于同等视觉效果的 PNG 或 JPEG 文件。因为它只存储了几个坐标和指令，而不是数百万个像素的颜色信息。

3.  **可编辑与可搜索**: 作为一个纯文本文件，SVG 可以被任何文本编辑器或代码编辑器打开和修改。你可以直接在代码中，改变一个形状的颜色、大小或位置。同时，SVG 文件中的文本内容，可以被搜索引擎索引，也可以被屏幕阅读器等辅助技术访问，具有良好的**可访问性 (Accessibility)**。

4.  **可通过 CSS 和 JavaScript 进行交互**: SVG 元素，可以像 HTML 元素一样，通过 CSS 来设置样式（如颜色、描边、动画），也可以通过 JavaScript 来响应用户的交互事件（如点击、悬停）。这使得 SVG 成为创建动态、可交互的数据可视化图表和网页动画的强大工具。

5.  **开放标准**: SVG 是由万维网联盟 (W3C) 维护的一个开放标准，得到了所有现代浏览器的原生支持，无需任何插件。

## 基本形状与路径

SVG 提供了一系列预定义的标签，用于创建基本形状：
*   `<rect>`: 矩形
*   `<circle>`: 圆形
*   `<ellipse>`: 椭圆
*   `<line>`: 直线
*   `<polyline>`: 折线
*   `<polygon>`: 多边形

然而，SVG 最强大的绘图工具，是 **`<path>`** 标签。

`<path>` 元素通过一个 `d` 属性，来定义一个极其灵活的路径数据。这个数据，由一系列的“命令”和“坐标”组成。

**路径命令示例**: 
*   `M x y`: **M**ove to (移动到)，将画笔移动到指定的 `(x, y)` 坐标。
*   `L x y`: **L**ine to (画直线到)，从当前点，画一条直线到指定的 `(x, y)` 坐标。
*   `H x`: **H**orizontal line to (画水平线到)，画一条水平线到指定的 `x` 坐标。
*   `V y`: **V**ertical line to (画垂直线到)，画一条垂直线到指定的 `y` 坐标。
*   `C x1 y1, x2 y2, x y`: **C**urve to (画贝塞尔曲线到)，使用两个控制点 `(x1, y1)` 和 `(x2, y2)`，画一条三次贝塞尔曲线到终点 `(x, y)`。
*   `A rx ry ...`: **A**rc to (画弧线到)。
*   `Z`: **Z** (ClosePath)，闭合路径，即从当前点，画一条直线，回到路径的起始点。

通过组合这些路径命令，你可以绘制出任何你能想象到的、任意复杂的二维形状。

## SVG 的应用场景

*   **Logo 和图标**: 这是 SVG 最理想的应用场景。Logo 和图标，需要在不同的地方、以不同的大小显示，而 SVG 的可缩放性，完美地满足了这一需求。
*   **数据可视化**: 使用 D3.js 等 JavaScript 库，可以动态地生成 SVG 图表（如柱状图、折线图、饼图），并为其添加丰富的交互效果。
*   **网页动画**: 通过 CSS 或 JavaScript，可以对 SVG 的属性（如位置、颜色、路径形状）进行动画处理，创造出比 GIF 或视频更轻量、更平滑的动画效果。
*   **交互式地图**: 可以用 SVG 来绘制地图，并让用户能够点击和交互地图上的不同区域。
*   **UI 设计与原型**: 许多现代的 UI 设计工具（如 Figma, Sketch），都以矢量图形作为其核心，并支持导出为 SVG 格式。

## 总结

SVG 是一种用**代码**和**数学**来描述图形的、强大而灵活的现代图像格式。

*   **核心**: 基于 XML 的**矢量**图形格式。
*   **最大优势**: **分辨率无关**，无限缩放而不失真。
*   **关键特性**: 文件体积小、可编辑、可交互、可访问。
*   **最强工具**: **`<path>`** 标签，能够通过指令，绘制任意复杂的形状。

与位图（如 PNG, JPEG）相比，SVG 不适合用来表示照片等具有复杂、连续色调的图像。但对于所有由清晰的线条、形状和颜色组成的图形来说，SVG 都是当之无愧的最佳选择。它代表了一种更语义化、更具结构性、也更适应现代 Web 开发需求的图形处理方式。
