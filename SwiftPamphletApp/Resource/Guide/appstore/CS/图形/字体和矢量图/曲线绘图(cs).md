# 曲线绘图：贝塞尔曲线

在计算机图形学和矢量绘图中，我们看到的几乎所有平滑、优美的曲线，其背后，都有一个共同的数学基础——**贝塞尔曲线 (Bézier Curves)**。从字体的轮廓，到 SVG 图标，再到 UI 动画的缓动曲线，贝塞尔曲线无处不在。

贝塞尔曲线是一种**参数曲线 (Parametric Curve)**，它由一系列的“**控制点 (Control Points)**”来定义。通过移动这些控制点，设计师和开发者，可以直观地、可预测地，改变曲线的形状。

## 德卡斯特里奥算法 (De Casteljau's Algorithm)

理解贝塞尔曲线最直观的方式，是理解其几何构造过程，即“德卡斯特里奥算法”。这个算法的核心，是**线性插值 (Linear Interpolation)**。

**线性插值 (Lerp)**: 
给定两个点 `P0` 和 `P1`，以及一个参数 `t` (从 0 到 1)，在这两点之间进行线性插值，会得到一个新的点 `P`，其计算公式为：
`P = (1 - t) * P0 + t * P1`
当 `t=0` 时，`P = P0`；当 `t=1` 时，`P = P1`；当 `t=0.5` 时，`P` 恰好位于 `P0` 和 `P1` 的中点。

### 1. 二次贝塞尔曲线 (Quadratic Bézier Curve)

一条二次贝塞尔曲线，由**三个**控制点定义：
*   `P0`: 起始点 (Anchor Point)
*   `P1`: 控制点 (Control Point)
*   `P2`: 结束点 (Anchor Point)

**构造过程**: 
对于一个给定的 `t` (从 0 到 1)：
1.  在 `P0` 和 `P1` 之间，进行线性插值，得到点 `Q0`。
2.  在 `P1` 和 `P2` 之间，进行线性插值，得到点 `Q1`。
3.  最后，在 `Q0` 和 `Q1` 之间，再次进行线性插值，得到点 `B`。

当 `t` 从 0 变化到 1 时，点 `B` 所扫过的轨迹，就是这条二次贝塞尔曲线。

```mermaid
graph TD
    subgraph t = 0.5
        P0 -- Q0 --- P1
        P1 -- Q1 --- P2
        Q0 -- B ---- Q1
    end
```

### 2. 三次贝塞尔曲线 (Cubic Bézier Curve)

三次贝塞尔曲线，是最常用、最重要的一种。它由**四个**控制点定义：
*   `P0`: 起始点
*   `P1`: 控制点 1
*   `P2`: 控制点 2
*   `P3`: 结束点

**构造过程**: 
它是在二次贝塞尔曲线的基础上，再增加一层线性插值。
对于一个给定的 `t`：
1.  在 `P0-P1`, `P1-P2`, `P2-P3` 之间，分别插值得到 `Q0`, `Q1`, `Q2`。
2.  在 `Q0-Q1`, `Q1-Q2` 之间，分别插值得到 `R0`, `R1`。
3.  最后，在 `R0-R1` 之间，插值得到点 `B`。

当 `t` 从 0 变化到 1 时，点 `B` 的轨迹，就是这条三次贝塞尔曲线。

**重要特性**: 
*   曲线一定通过起始点 `P0` 和结束点 `P3`。
*   曲线在 `P0` 点的切线方向，由 `P0-P1` 这条线段的方向决定。
*   曲线在 `P3` 点的切线方向，由 `P2-P3` 这条线段的方向决定。

这个特性，使得我们可以将多段三次贝塞尔曲线，平滑地（C1 连续）拼接在一起，来构造任意复杂的形状。这正是所有矢量绘图软件（如 Adobe Illustrator）和字体（如 PostScript, TrueType）的核心工作原理。

## 在 SVG 和 Canvas 中使用

在 Web 和图形编程中，我们通常直接使用 API 来绘制贝塞尔曲线，而无需自己实现德卡斯特里奥算法。

### SVG `<path>` 元素

*   **二次贝塞尔曲线 (Q)**:
    `M x0,y0 Q x1,y1 x2,y2`
    *   `M`: 移动到起始点 `(x0, y0)`
    *   `Q`: 使用控制点 `(x1, y1)`，画一条二次贝塞尔曲线到结束点 `(x2, y2)`。

*   **三次贝塞尔曲线 (C)**:
    `M x0,y0 C x1,y1 x2,y2 x3,y3`
    *   `C`: 使用两个控制点 `(x1, y1)` 和 `(x2, y2)`，画一条三次贝塞尔曲线到结束点 `(x3, y3)`。

### HTML5 Canvas API

*   **二次贝塞尔曲线**:
    ```javascript
    ctx.beginPath();
    ctx.moveTo(x0, y0);
    ctx.quadraticCurveTo(x1, y1, x2, y2);
    ctx.stroke();
    ```

*   **三次贝塞尔曲线**:
    ```javascript
    ctx.beginPath();
    ctx.moveTo(x0, y0);
    ctx.bezierCurveTo(x1, y1, x2, y2, x3, y3);
    ctx.stroke();
    ```

## 缓动曲线 (Easing Curves)

贝塞尔曲线，不仅可以用来绘制空间中的形状，还可以用来描述**时间**上的变化率，即**动画的缓动曲线**。

在这种用法中，我们通常使用一个二维的三次贝塞尔曲线，其 X 轴代表**时间的百分比**（从 0% 到 100%），Y 轴代表**动画完成的百分比**（从 0% 到 100%）。

*   **起始点 `P0`** 总是 `(0, 0)`。
*   **结束点 `P3`** 总是 `(1, 1)`。

我们只需要定义**两个控制点 `P1(x1, y1)` 和 `P2(x2, y2)`** 的位置，就可以创建出各种各样的缓动效果。

*   **`ease-in`**: 加速曲线。`P1` 和 `P2` 的 Y 值，都比较小。
*   **`ease-out`**: 减速曲线。`P1` 和 `P2` 的 Y 值，都比较大。
*   **`ease-in-out`**: 先加速后减速曲线。

CSS 的 `transition-timing-function: cubic-bezier(x1, y1, x2, y2);` 属性，就是这种应用的直接体现。

## 总结

*   **贝塞尔曲线**是一种通过“**控制点**”来定义的、用于绘制平滑曲线的数学工具。
*   其几何构造，基于**多层嵌套的线性插值**（德卡斯特里奥算法）。
*   **二次贝塞尔曲线**由 3 个点定义，**三次贝塞尔曲线**由 4 个点定义。
*   三次贝塞尔曲线，是矢量绘图和字体技术的核心，因为它能够保证**端点处的切线连续**，从而可以平滑地拼接。
*   除了绘制空间形状，贝塞尔曲线也广泛地用于定义**动画的缓动曲线**。

理解贝塞尔曲线的原理，是从一个更深的层次，去理解所有矢量图形软件和现代 UI 动画系统的基础。它是一个连接了数学、设计和编程的、优美而强大的概念。
