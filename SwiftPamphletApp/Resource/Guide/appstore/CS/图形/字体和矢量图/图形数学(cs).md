# 图形数学基础：向量与矩阵

线性代数，特别是向量和矩阵的运算，是整个计算机图形学的数学基石。无论是 2D 还是 3D 图形，所有的位置、方向、缩放、变换和投影，最终都可以被描述为一系列的向量和矩阵运算。理解这些基本的数学概念，是理解图形渲染管线工作原理的前提。

## 向量 (Vectors)

在图形学中，一个向量，可以被看作是一个既有**大小 (Magnitude)**，又有**方向 (Direction)** 的量。它通常由一组有序的数字来表示，例如，一个三维向量 `v = (x, y, z)`。

向量在图形学中有两种主要的解释：

1.  **表示一个位置 (Position)**: 向量可以被用来表示空间中的一个**点**。例如，向量 `(5, 3, 0)`，可以表示在 3D 空间中，从原点出发，沿 X 轴走 5 个单位，沿 Y 轴走 3 个单位的点。

2.  **表示一个方向 (Direction)**: 向量也可以被用来表示一个**方向**和**大小**。例如，一个表示“风”的向量，其方向，指明了风吹向哪里；其大小（或称“模长”），则表示风的速度。

### 向量运算

*   **加法/减法**: 两个向量相加或相减，等于将它们的对应分量，分别相加或相减。在几何上，向量加法遵循“平行四边形法则”。
    `A + B = (Ax + Bx, Ay + By, Az + Bz)`

*   **标量乘法**: 一个向量，与一个标量（一个单独的数字）相乘，等于将其每一个分量，都与该标量相乘。这会缩放向量的长度，但不会改变其方向（除非标量为负）。
    `s * A = (s * Ax, s * Ay, s * Az)`

*   **点积 (Dot Product)**: 两个向量的点积，是一个**标量**。它的计算方式，是将两个向量的对应分量相乘，然后再相加。
    `A · B = Ax*Bx + Ay*By + Az*Bz`
    点积在几何上，等于两个向量的模长，乘以它们之间夹角的余弦值：`A · B = |A| * |B| * cos(θ)`。
    **应用**: 
        *   **计算角度**: 可以通过点积，来快速地计算两个向量之间的夹角。这在光照计算中，用于判断一个表面，与光源方向的夹角，从而决定其亮度。
        *   **投影**: 计算一个向量，在另一个向量上的投影长度。

*   **叉积 (Cross Product)**: 两个三维向量的叉积，是一个新的**向量**。这个新的向量，**同时垂直于**原来的两个向量。
    **应用**: 
        *   **计算法线**: 对于一个由两个向量定义的平面，可以通过它们的叉积，来快速地计算出这个平面的**法线向量 (Normal Vector)**。法线在 3D 光照计算中，至关重要。

## 矩阵 (Matrices)

一个矩阵，是一个由数字组成的二维矩形阵列。在计算机图形学中，矩阵是一种极其强大的工具，它被用来表示和执行各种**几何变换 (Geometric Transformations)**。

我们通常使用 4x4 的矩阵，来进行 3D 图形的变换。一个 3D 空间中的点（一个向量 `(x, y, z)`），为了能够与 4x4 矩阵相乘，需要被扩展为一个四维的“**齐次坐标 (Homogeneous Coordinate)**” `(x, y, z, 1)`。

### 核心的变换矩阵

1.  **平移矩阵 (Translation Matrix)**: 用于将一个物体，在空间中移动。

2.  **缩放矩阵 (Scale Matrix)**: 用于将一个物体，进行放大或缩小。

3.  **旋转矩阵 (Rotation Matrix)**: 用于将一个物体，围绕某个坐标轴（X, Y, 或 Z 轴）进行旋转。

### 矩阵的组合

矩阵变换最强大的地方，在于它们可以被**组合**在一起。如果你想对一个物体，先进行缩放，然后旋转，最后再平移，你不需要分三步来对物体的每一个顶点，都进行计算。相反，你可以先将**缩放矩阵**、**旋转矩阵**和**平移矩阵**，这三个矩阵，**预先相乘**，得到一个单一的、组合的“**模型矩阵 (Model Matrix)**”。

`Model Matrix = Translation Matrix * Rotation Matrix * Scale Matrix`

然后，你只需要用这个最终的模型矩阵，去乘以物体的每一个顶点，就可以一次性地，完成所有的变换。**注意：矩阵乘法不满足交换律，变换的顺序非常重要！**

### MVP 矩阵

在 3D 渲染管线中，一个顶点，从其在 3D 模型中的局部位置，到最终被投影到 2D 屏幕上，需要经历一系列的矩阵变换。这个过程，通常由三个核心的矩阵来完成：

1.  **模型矩阵 (Model Matrix)**: 将顶点，从**模型空间**，变换到**世界空间**。
2.  **视图矩阵 (View Matrix)**: 将顶点，从**世界空间**，变换到**视图空间**（摄像机空间）。
3.  **投影矩阵 (Projection Matrix)**: 将顶点，从**视图空间**，变换到**裁剪空间**（一个从 -1 到 +1 的规范化立方体）。

这三个矩阵，通常会在 CPU 端，被预先相乘，得到一个单一的 **MVP 矩阵**，然后被传递给 GPU 上的顶点着色器。

`MVP Matrix = Projection Matrix * View Matrix * Model Matrix`

顶点着色器的核心工作，就是执行以下这个运算：

`gl_Position = MVP * vertex_position_in_model_space`

## 总结

*   **向量**是描述**位置**和**方向**的基本工具。
    *   **点积**用于计算**角度**和**投影**。
    *   **叉积**用于计算**法线**。
*   **矩阵**是执行**几何变换**（平移、旋转、缩放）的基本工具。
*   矩阵变换，可以通过**矩阵乘法**，被**组合**在一起。
*   **MVP 矩阵** (模型-视图-投影)，是将一个 3D 顶点，从其局部空间，最终投影到屏幕裁剪空间的、核心的变换矩阵。

虽然现代的图形 API 和游戏引擎，已经为我们封装好了大量的矩阵和向量运算，但理解这些运算背后的数学原理，对于我们深入地理解 3D 渲染的本质、编写高效的着色器代码、以及解决复杂的图形问题，都是不可或缺的。
