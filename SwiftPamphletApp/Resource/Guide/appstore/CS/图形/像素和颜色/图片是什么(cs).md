# 图片是什么？

在数字世界中，我们每天都会看到和使用无数的图片。但从计算机的角度来看，一张图片，本质上只是一个由数字组成的、巨大的**二维网格 (2D Grid)**。这个网格中的每一个最小单元，都被称为“**像素 (Pixel)**”，是“Picture Element”的缩写。

## 像素与颜色

每一个像素，都存储了一个**颜色**信息。这个颜色信息，通常由三个或四个数值来表示：

*   **R (Red, 红色)**
*   **G (Green, 绿色)**
*   **B (Blue, 蓝色)**

这被称为 **RGB 色彩模型**，它是基于“**加色混合 (Additive Color)**”原理的。即，通过将不同强度的红、绿、蓝三原色光，混合在一起，可以创造出各种不同的颜色。当红、绿、蓝都为最大值时，混合成白色；都为最小值时，则是黑色。

### 颜色深度 (Color Depth)

每个颜色通道（R, G, B）的强度，通常用一个 8 位的无符号整数来表示，其取值范围是 **0 到 255**。

*   `0` 代表该颜色通道的强度为 0%。
*   `255` 代表该颜色通道的强度为 100%。

因此，一个像素的颜色，可以用三个 0-255 的整数来表示，例如：
*   `(255, 0, 0)`: 纯红色
*   `(0, 255, 0)`: 纯绿色
*   `(0, 0, 255)`: 纯蓝色
*   `(0, 0, 0)`: 黑色
*   `(255, 255, 255)`: 白色
*   `(255, 255, 0)`: 黄色 (红 + 绿)

由于每个通道有 256 种可能性，所以一个标准的 24 位 RGB 像素，总共可以表示 `256 * 256 * 256 = 16,777,216` 种不同的颜色，这通常被称为“**真彩色 (True Color)**”。

### Alpha 通道：透明度

除了 R, G, B 三个颜色通道外，图片通常还包含第四个通道：**Alpha (A)**。

*   **Alpha 通道**也用一个 0-255 的整数来表示，它定义了这个像素的**不透明度 (Opacity)**。
    *   `255` 代表完全不透明。
    *   `0` 代表完全透明。
    *   中间值则代表半透明。

这种包含 Alpha 通道的 32 位颜色表示法，被称为 **RGBA**。

## 图片的分辨率与文件大小

*   **分辨率 (Resolution)**: 指的是一张图片在宽度和高度上，所包含的像素数量。例如，一张分辨率为 `1920 x 1080` 的图片，意味着它由一个 1920 列、1080 行的像素网格组成，总共包含了 `1920 * 1080 = 2,073,600` 个像素。

*   **文件大小**: 一张未经压缩的图片，其文件大小，可以直接由其分辨率和颜色深度计算得出。
    *   对于一张 `1920 x 1080` 的 32 位 RGBA 图片，其未经压缩的大小为：
        `1920 (宽) * 1080 (高) * 4 (字节/像素) = 8,294,400 字节 ≈ 8.3 MB`

## 位图 vs. 矢量图

我们上面所描述的、由像素网格组成的图片，被称为“**位图 (Bitmap)**”或“**光栅图 (Raster Graphics)**”。我们日常接触到的大多数图片格式，如 **JPEG, PNG, GIF, BMP**，都属于位图。

**位图的特点**: 
*   **优点**: 能够非常逼真地，表现照片、绘画等具有复杂颜色和纹理的图像。
*   **缺点**: **分辨率依赖 (Resolution-dependent)**。当你将一张位图放大时，你会开始看到一个个独立的像素块，图像会变得模糊和“马赛克化”。

与位图相对的，是“**矢量图 (Vector Graphics)**”。

*   **核心思想**: 矢量图不是通过记录每一个像素的颜色，来描述图像的。相反，它是通过一系列的**数学方程式**，来描述图像中的**点、线、曲线和形状**。
*   **例子**: 一个圆，在矢量图中，可能被描述为“一个位于坐标 (100, 100)、半径为 50px、填充色为红色的圆形”。
*   **优点**: **分辨率无关 (Resolution-independent)**。由于形状是由数学公式定义的，你可以将一张矢量图，无限地放大，而它永远不会失真，其边缘始终是平滑、锐利的。
*   **缺点**: 难以表现照片那样具有复杂、连续色调的图像。
*   **常见格式**: **SVG, AI (Adobe Illustrator), PDF** (可以同时包含位图和矢量图)。

## 总结

| 特性 | 位图 (Bitmap / Raster) | 矢量图 (Vector) |
| :--- | :--- | :--- |
| **基本单元** | 像素 (Pixel) | 数学路径 (Path) |
| **描述方式** | 记录每个像素的颜色值 | 记录点、线、曲线的数学方程式 |
| **缩放** | 放大后会失真、模糊 | **无限缩放而不失真** |
| **文件大小** | 与分辨率和颜色复杂度成正比 | 与形状的复杂度成正比 |
| **适用场景** | **照片**、复杂的绘画、纹理 | **Logo**、图标、字体、图表、插画 |
| **常见格式** | JPEG, PNG, GIF | SVG, AI, PDF |

从根本上说，我们屏幕上显示的**所有内容**，最终都是以**像素**的形式呈现的。即使是矢量图，在被显示之前，也需要经过一个被称为“**光栅化 (Rasterization)**”的过程，即计算出这些数学形状，最终覆盖了屏幕上的哪些像素，以及这些像素应该是什么颜色。

理解图片是由像素构成的，以及位图和矢量图的根本区别，是进行任何数字图形设计、图像处理或 UI 开发的基础。
