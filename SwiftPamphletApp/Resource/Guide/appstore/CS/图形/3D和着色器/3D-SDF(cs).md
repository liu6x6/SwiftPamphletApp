# 3D 图形：符号距离场 (SDF)

符号距离场（Signed Distance Fields, SDF），又称符号距离函数（Signed Distance Functions），是一种在计算机图形学、特别是实时渲染和 3D 建模中，越来越受欢迎的、用于表示几何形状的强大技术。与传统的、用三角形网格（Meshes）来表示模型表面的方法不同，SDF 描述的是**空间中任意一点，到某个几何形状表面的最短距离**。

## 核心理念

一个 SDF，本质上就是一个函数 `f(p)`，其中 `p` 是空间中的一个点（一个三维向量 `(x, y, z)`）。这个函数的返回值，是一个标量，其含义如下：

*   **`f(p) > 0`**: 点 `p` 在形状的**外部**，其值表示 `p` 到形状表面的最短距离。
*   **`f(p) < 0`**: 点 `p` 在形状的**内部**，其绝对值 `|f(p)|` 表示 `p` 到形状表面的最短距离。
*   **`f(p) = 0`**: 点 `p` 恰好在形状的**表面**上。

因此，这个几何形状的表面，被隐式地（implicitly）定义为了所有满足 `f(p) = 0` 的点的集合。

**例子：一个球体的 SDF**

一个位于原点、半径为 `r` 的球体，其 SDF 函数非常简单：

```
f(p) = length(p) - r
```

其中 `length(p)` 是点 `p` 到原点的距离。你可以清楚地看到：
*   如果 `length(p) > r`，点在球外，结果为正。
*   如果 `length(p) < r`，点在球内，结果为负。
*   如果 `length(p) = r`，点在球表面，结果为零。

## SDF 的优势

### 1. 任意分辨率与平滑表面

由于形状是由一个连续的数学函数定义的，而不是由离散的三角形组成的，SDF 能够表示任意平滑的、没有锯齿的表面。无论你将一个 SDF 渲染的图像放大多少倍，它的边缘始终是完美平滑的。

### 2. 强大的布尔运算

这是 SDF 最神奇、最强大的特性之一。通过对两个 SDF 函数的返回值，进行简单的 `min` 和 `max` 操作，就可以实现复杂的几何体布尔运算（并集、交集、差集）。

假设我们有两个形状，其 SDF 分别为 `sdfA` 和 `sdfB`：

*   **并集 (Union)**: `min(sdfA(p), sdfB(p))`
    *   这会得到一个包含了 A 和 B 所有部分的新形状。
*   **交集 (Intersection)**: `max(sdfA(p), sdfB(p))`
    *   这会得到一个只包含 A 和 B 重叠部分的新形状。
*   **差集 (Difference)**: `max(sdfA(p), -sdfB(p))`
    *   这会得到一个从 A 中减去 B 的新形状。

通过将球体、立方体、圆环等基本形状（Primitives）的 SDF，用这种方式进行组合，我们可以用很少的代码，构建出极其复杂的几何形态。

### 3. 高效的碰撞检测与光线步进

SDF 的值，直接告诉了我们，从当前点出发，可以沿着任意方向，安全地前进多远的距离，而不会碰到任何物体的表面。这个特性，使得 SDF 在“**光线步进 (Ray Marching)**”渲染算法中，具有极高的效率。

与传统的光线追踪（Ray Tracing）需要精确计算光线与三角形交点不同，光线步进的算法是：

1.  从摄像机发射一条光线。
2.  计算光线当前所在点 `p` 的 SDF 值 `d = sdf(p)`。
3.  如果 `d` 非常接近于 0，说明光线已经碰到了表面，停止步进。
4.  否则，将光线沿着其方向，向前推进 `d` 的距离。
5.  重复步骤 2-4。

这种方法，可以用远少于传统光线追踪的计算量，来渲染出复杂的 3D 场景，因此在实时渲染（例如 ShaderToy 上的许多作品）中非常流行。

## SDF 的应用

*   **实时渲染与着色器艺术**: 在 ShaderToy, GLSL Sandbox 等平台上，艺术家和程序员们使用 SDF 和光线步进，来创作令人惊叹的、程序生成的实时 3D 动画和分形艺术。

*   **字体渲染**: Valve 公司在游戏《军团要塞2》中，首次提出了使用 2D SDF 来进行高质量、任意缩放的字体渲染。生成的 SDF 纹理，可以被硬件高效地渲染，并且在任何分辨率下，都能保持字形的锐利边缘。

*   **3D 建模与游戏开发**: 一些现代的 3D 建模工具（如 Dreams, Clayxels）和游戏引擎，开始原生支持基于 SDF 的建模和渲染，使得艺术家可以像捏橡皮泥一样，直观地进行创作。

*   **物理模拟**: SDF 可以非常高效地，进行物体之间的碰撞检测。

## 局限性

*   **表示能力的限制**: 传统的 SDF，难以表示没有“内部”和“外部”之分的、无限薄的平面，或者带有复杂、高频细节的表面（例如，一张褶皱的纸）。
*   **动画的挑战**: 对一个由 SDF 定义的复杂形状进行动画，特别是骨骼动画，比操作传统的三角形网格要更具挑战性。
*   **硬件加速**: 目前主流的 GPU 硬件，是为渲染三角形而高度优化的。虽然 SDF 可以通过着色器（Shader）来高效地渲染，但它还没有像三角形光栅化那样，得到底层的、专门的硬件支持。

## 总结

符号距离场 (SDF) 是一种优雅而强大的、隐式地表示几何形状的数学工具。它将复杂的几何问题，转化为了简单的数学函数运算。

*   **核心**: 用一个函数，来描述空间中任意一点，到物体表面的**有符号**最短距离。
*   **优势**: 能够表示**平滑表面**，支持强大的**布尔运算**，并且能与**光线步进**算法完美结合，实现高效的实时渲染。
*   **应用**: 广泛应用于**实时图形、字体渲染、3D 建模**等领域。

与传统的、以三角形网格为基础的“显式”几何表示方法相比，SDF 提供了一种全新的、程序化的、更具数学美感的“隐式”建模范式。随着 GPU 计算能力的不断增强和相关算法的不断成熟，SDF 在未来的计算机图形学领域，必将扮演越来越重要的角色。
