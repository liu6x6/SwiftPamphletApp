# LLM 是如何工作的？

大型语言模型（Large Language Models, LLM），如 GPT-4, Llama, Claude 等，其核心工作原理可以被惊人地简化为一句话：**一次一个词地、预测下一个最有可能出现的词**。

这听起来很简单，但正是通过在一个极其庞大的文本数据集上，对这个“预测下一个词”的任务进行反复的、大规模的训练，LLM 才涌现出了我们今天所看到的、令人惊叹的语言理解、生成、推理和知识能力。

## 核心步骤

一个 LLM 的工作流程，主要可以分为以下几个步骤：

### 1. 文本分词 (Tokenization)

计算机无法直接理解人类的文字。第一步，是需要将输入的文本（Prompt）分解成一系列的、模型能够理解的最小单元，这些单元被称为“**词元 (Tokens)**”。

*   **什么是 Token？** 一个 Token 可以是一个完整的单词（如 `apple`），也可以是一个词根（如 `runn`ing 中的 `runn`）、一个标点符号，甚至是一个汉字。
*   **分词器 (Tokenizer)**: 这个过程由一个专门的“分词器”来完成。分词器拥有一个巨大的“词汇表 (Vocabulary)”，它会将输入的文本，切分成词汇表中存在的、最长的 Token 序列。
*   **例子**: `I have an apple` 可能会被分解为 `["I", "have", "an", "apple"]`。而 `running` 可能会被分解为 `["runn", "ing"]`。

### 2. 词嵌入 (Embedding)

分词后，每个 Token 都需要被转换成一个由数字组成的**向量 (Vector)**。这个过程被称为“词嵌入”。

*   **为什么需要 Embedding？** 向量可以被看作是这个 Token 在一个高维“语义空间”中的坐标。在这个空间中，意思相近的 Token（如“猫”和“狗”）在空间中的距离，会比意思无关的 Token（如“猫”和“香蕉”）更近。
*   **Embedding 层**: 模型的第一层，就是一个巨大的查询表（Embedding Layer）。它存储了词汇表中每一个 Token 所对应的、预先训练好的词嵌入向量。
*   **结果**: 输入的 Token 序列，现在变成了一个由向量组成的序列。这个向量序列，才能够被神经网络进行数学运算。

### 3. Transformer 神经网络

这是 LLM 的核心引擎。输入的词嵌入向量序列，会流经一个由数十层甚至上百层 **Transformer Block** 堆叠而成的深度神经网络。

每一层 Transformer Block，主要做两件事：

*   **自注意力机制 (Self-Attention)**: 这是 Transformer 最关键的创新。对于序列中的每一个 Token，自注意力机制会计算它与序列中**所有其他** Token 之间的“相关性”或“注意力分数”。这使得模型能够理解一个词在当前上下文中的确切含义。例如，在 `bank of the river` 中，`bank` 这个词的注意力，会更多地被 `river` 所吸引，从而使其含义偏向于“河岸”，而不是“银行”。

*   **前馈网络 (Feed-Forward Network)**: 在经过自注意力机制的“上下文混合”之后，每个 Token 的向量，会再经过一个标准的前馈神经网络，进行进一步的、非线性的特征提取和转换。

这个过程会在数十个 Transformer Block 中被反复地、逐层地进行。随着层数的加深，模型对输入文本的语义理解，也变得越来越深刻和抽象。

### 4. 预测下一个词 (Prediction)

当最后一个 Transformer Block 处理完所有输入的 Token 后，它会输出一个最终的向量。这个向量，可以被看作是模型对整个输入序列的“思考”和“理解”的结晶。

*   **Softmax 层**: 这个最终的向量，会被送入一个 Softmax 层。Softmax 层会将其转换成一个**概率分布**，这个概率分布的维度，与模型的词汇表大小完全相同。
*   **概率分布的含义**: 这个概率分布中的每一个值，都对应着词汇表中的一个 Token，代表了模型预测**下一个**出现的 Token 是该 Token 的概率。例如，`P("is") = 0.05`, `P("was") = 0.02` 等。

### 5. 采样 (Sampling)

现在，模型有了一个关于下一个最有可能出现的词的概率列表。最后一步，就是从这个列表中，选择一个词作为最终的输出。

*   **贪心搜索 (Greedy Search)**: 最简单的方法，是永远选择概率最高的那个 Token。这种方法虽然安全，但生成的文本往往会非常单调、重复和缺乏创造性。
*   **温度采样 (Temperature Sampling)**: 为了增加文本的多样性，通常会引入一个“温度 (Temperature)”参数。较高的温度，会使得低概率的 Token 也更有可能被选中，从而产生更具创造性、更“惊艳”的输出；而较低的温度，则会使得输出更集中于高概率的 Token，产生更稳定、更符合事实的输出。
*   **Top-K / Top-P 采样**: 只在概率最高的 K 个 Token 或累积概率达到 P 的 Token 集合中，进行采样，以避免选中那些极其不相关的词。

### 6. 自回归 (Auto-regression)

一旦模型选择并输出了一个 Token，这个新的 Token 就会被**添加**到原始输入序列的末尾，形成一个新的、更长的序列。然后，整个过程（从 Embedding 到 Sampling）会再次重复，以预测再下一个 Token。

这个“**将自己的输出，作为下一次输入的一部分**”的过程，被称为“自回归”。LLM 就是通过这种自回归的方式，一次一个词地，生成了我们所看到的、完整的句子和段落。

## 总结

LLM 的工作原理，是一个将符号（文字）转化为数字（向量），通过深度神经网络进行复杂运算，再将结果从数字（概率分布）转化回符号（文字）的、不断循环的过程。

1.  **分词 (Tokenization)**: 文字 -> 词元 (Tokens)
2.  **词嵌入 (Embedding)**: 词元 -> 向量 (Vectors)
3.  **Transformer**: 通过自注意力机制，对向量序列进行深度的上下文理解和特征转换。
4.  **预测 (Prediction)**: 输出一个关于下一个词的概率分布。
5.  **采样 (Sampling)**: 根据概率分布，并结合温度等参数，选择一个词作为输出。
6.  **自回归 (Auto-regression)**: 将新生成的词，加入到输入中，然后重复整个过程。

正是这个看似简单的、不断预测下一个词的循环，在海量数据和巨大计算规模的加持下，使得 LLM 能够涌现出令人难以置信的智能。
