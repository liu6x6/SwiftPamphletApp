# 图像压缩

一张未经压缩的、高分辨率的数字图像，会占用巨大的存储空间。例如，一张 1200 万像素的 iPhone 照片，如果未经压缩，其大小将超过 34 MB。为了能够在互联网上高效地传输和存储图像，我们必须对其进行**压缩**。

图像压缩，分为两大类：**无损压缩 (Lossless Compression)** 和 **有损压缩 (Lossy Compression)**。

## 1. 无损压缩 (Lossless Compression)

*   **核心思想**: 在不丢失**任何**原始图像信息的前提下，通过更智能的编码方式，来减小文件大小。解压缩后的图像，与原始图像，在像素级别上，是**完全相同**的。
*   **常用格式**: **PNG, GIF, BMP (RLE), TIFF (LZW)**

### 无损压缩是如何工作的？

无损压缩，主要利用了图像数据中的“**冗余 (Redundancy)**”。

1.  **预测 (Prediction)**: 压缩算法会首先尝试“预测”下一个像素的颜色值，通常是基于其相邻像素的颜色。例如，一个简单的预测器，可能会假设下一个像素，与它左边的像素，颜色相同。

2.  **编码残差 (Encoding Residuals)**: 然后，算法只记录下**预测值**与**实际值**之间的“**差值**”（被称为“残差”）。对于大面积的、颜色平坦的区域（如蓝天、白墙），这个差值，在大多数情况下，都会是 0。因此，原始的一长串重复的颜色值（如 `(0,0,255), (0,0,255), ...`），就被转换成了一长串的 `0`。

3.  **熵编码 (Entropy Coding)**: 最后，使用像**霍夫曼编码 (Huffman Coding)** 或**算术编码**这样的熵编码算法，来对这些差值，进行最终的压缩。熵编码的原理是，为出现频率更高的值（在这里，就是 `0`），分配更短的二进制编码；为出现频率更低的值，分配更长的编码。这就像摩尔斯电码中，最常用的字母 `E`，其编码最短（一个点）一样。

**PNG (Portable Network Graphics)** 是最先进的无损压缩格式之一。它在进行预测之前，会先对图像数据，进行一系列的“**预过滤 (Prefiltering)**”，以找到能产生最多 `0` 差值的最佳预测模型，从而达到更高的压缩率。

## 2. 有损压缩 (Lossy Compression)

*   **核心思想**: 为了获得**远高于**无损压缩的压缩率，有损压缩，会**永久性地、选择性地**丢弃掉一部分在人眼看来“不那么重要”的图像信息。
*   **常用格式**: **JPEG, WebP, HEIC, AVIF**

### JPEG 压缩是如何工作的？

JPEG 是最经典、最流行的有损压缩格式。其压缩过程，主要包含以下几个利用了人类视觉系统 (HVS) 特性的步骤：

1.  **色彩空间转换**: 首先，将图像从 RGB 色彩空间，转换为 **YCbCr** 色彩空间。
    *   `Y`: **亮度 (Luma)**，即图像的明暗信息。
    *   `Cb`, `Cr`: **色度 (Chroma)**，即图像的色彩信息。
    *   **原因**: 人类的眼睛，对**亮度**的变化，远比对**色彩**的变化，更为敏感。

2.  **色度抽样 (Chroma Subsampling)**: 利用人眼对色彩不敏感的特性，对色度通道 `Cb` 和 `Cr`，进行“**降采样**”。例如，在 `4:2:0` 抽样中，每 4 个像素，只保留一组色度信息。这一步，可以在几乎不影响视觉质量的情况下，直接将图像数据的体积，减少一半。

3.  **离散余弦变换 (Discrete Cosine Transform, DCT)**: 这是 JPEG 压缩的**核心**。算法会将图像，分割成一个个 8x8 的像素块。对于每一个块，都进行一次 DCT 变换。DCT 会将一个空间域的、由 64 个像素值组成的块，转换为一个频率域的、由 64 个“**频率系数**”组成的块。
    *   **能量集中**: DCT 变换后，图像的大部分“能量”或“信息”，都会集中在左上角的、少数几个**低频系数**上。而右下角的大多数**高频系数**（它们代表了图像中颜色变化剧烈的部分，如边缘和噪点），其值都非常接近于 0。

4.  **量化 (Quantization)**: 这是**有损**的部分。算法会使用一个“量化表”，来对 DCT 变换后的 64 个频率系数，进行一次“粗略的除法”。对于人眼不敏感的高频系数，会使用一个更大的量化步长（即除以一个更大的数），从而使得这些系数，在除法后，有更多的值，变成了 0。JPEG 的“**质量**”参数（例如，从 1 到 100），就是用来控制这个量化表的粗糙程度的。质量越低，量化步长越大，被丢弃的信息就越多，文件就越小。

5.  **熵编码**: 最后，对量化后的系数，进行熵编码（通常是霍夫曼编码），来进一步地压缩数据。

## 无损 vs. 有损：如何选择？

| 特性 | 无损压缩 (PNG) | 有损压缩 (JPEG) |
| :--- | :--- | :--- |
| **图像质量** | **完美**，与原始图像完全相同 | **有损**，会产生压缩瑕疵 (Artifacts) | 
| **压缩率** | 有限，通常为 2:1 到 3:1 | **非常高**，可达到 10:1, 20:1 甚至更高 |
| **Alpha 通道** | **支持** | **不支持** (标准 JPEG) |
| **适用场景** | **Logo, 图标, UI 元素, 线条画**，以及任何需要精确像素和透明度的图像 | **照片**，以及任何具有复杂、连续色调的自然图像 |

**一个重要的原则**: **永远不要重复地，对一张 JPEG 图像，进行有损压缩**。每一次的 JPEG 压缩，都是一次新的信息损失。如果你需要多次编辑一张图片，你应该始终在一个无损的格式（如 PSD, TIFF, PNG）上进行，只在最后输出最终版本时，才将其保存为 JPEG。

## 现代图像格式：WebP, HEIC, AVIF

这些是比 JPEG 更现代、更高效的有损压缩格式。它们借鉴了现代视频编码（如 VP8, HEVC, AV1）中的许多先进技术（如更灵活的块划分、更先进的预测模型），从而能够在与 JPEG 相同的视觉质量下，达到**更高**的压缩率（通常能再节省 30%-50% 的体积）。此外，它们也都支持**无损压缩**模式和 **Alpha 通道**。
