# visionOS 空间设计原则 (Spatial Design)

visionOS 引入了一种全新的设计范式：**空间计算 (Spatial Computing)**。将 iOS 的二维 UI 直接生搬硬套到三维空间是行不通的。Apple 在 Human Interface Guidelines (HIG) 中对 visionOS 提出了极其详尽的设计规范。

## 1. 核心设计理念

### 空间与深度 (Space and Depth)
*   界面不再被局限在一个物理屏幕上，而是悬浮在用户的物理环境中。
*   **深度（Z轴）**不应该被滥用。不要让 UI 元素离用户太近（会引起压迫感和眼球疲劳），也不要太远。
*   **层级关系**：使用 z 轴和投影来表示层级。激活的模态窗口（Modal）应该在 Z 轴上稍微向前凸出一点，并对后方的界面投射阴影。

### 材质与光影 (Materials and Lighting)
*   **玻璃材质 (Glass Material)**：visionOS 的核心 UI 背景。它不是纯粹的透明或毛玻璃，而是一种能动态反射周围真实环境光线和色彩的材质。这能让数字界面完美融入用户的客厅或办公室。
*   绝对不要使用纯不透明的纯色（如纯白、纯黑）作为大面积背景，这会像一块纸板一样阻断用户的现实视线，带来极其突兀的割裂感。

## 2. 窗口 (Windows) 与 排版

*   **窗口形状**：尽量保持窗口是柔和的圆角矩形。
*   **无边界设计**：不需要像 macOS 那样有明确的顶部标题栏拖拽区。visionOS 的窗口底部会有一个悬浮的控制条用于移动和关闭窗口。
*   **排版方向**：内容应该主要横向或纵向延伸，避免过大导致用户需要频繁转动脖子。视野的核心区域大约在正前方 60 度锥角内。

## 3. 交互方式 (Interaction)

visionOS 的基础交互是**“眼动追踪 (注视) + 捏合 (点击)”**。
*   **注视反馈 (Hover Effect)**：因为用户是用眼睛来充当鼠标指针的，所以每一个可点击的按钮（Button, Tab）在被用户注视时，必须有明确的视觉反馈（通常是高亮或者轻微的前凸）。系统原生控件会自动处理这一点，自定义控件必须加上 \`.hoverEffect()\` 修饰符。
*   **热区大小**：因为眼睛的注视会有微小的跳动，控件的热区（Hit Target）必须足够大（推荐最小 60x60 点），控件之间要有足够的间距（至少 16 点）。

## 4. 沉浸感级别 (Immersion Levels)

设计应用时，要明确应用处于哪种沉浸状态：
*   **Window (窗口)**：应用像卡片一样悬浮，用户可以看到物理世界和其他 App。
*   **Volume (体积)**：展示 3D 内容（如一个漂浮的地球仪），用户可以绕着它走，但周围仍然是物理世界。
*   **Immersive Space (完全沉浸空间)**：例如虚拟影院或 VR 游戏。现实世界被完全隐藏，应用接管 100% 的视野。必须提供明确的退出机制（通常通过按压硬件数字表冠）。
