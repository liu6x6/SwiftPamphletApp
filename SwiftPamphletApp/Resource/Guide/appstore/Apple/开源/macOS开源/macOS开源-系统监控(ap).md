# macOS 开源：系统状态监控工具

macOS 平台上的系统监控类应用（如 iStat Menus 的开源竞品）是非常受欢迎的极客工具。这类项目往往需要深入到 macOS 底层的 C/C++ API 和内核调用（Darwin XNU），是学习 macOS 底层运作机制的绝佳材料。

## 1. 殿堂级监控项目

*   **Stats** (纯 Swift / C)
    *   **简介**：目前 GitHub 上最火、也是最漂亮的 macOS 免费开源系统监视器。它常驻在菜单栏，能实时显示 CPU、内存、磁盘、网络和传感器的状态。
    *   **学习点**：这是学习 macOS 菜单栏（MenuBar / NSStatusItem）开发的终极教材。

*   **Eul**
    *   **简介**：另一款非常有名的、全部使用 SwiftUI 编写的 macOS 状态监控工具。
    *   **学习点**：如何用最新的 SwiftUI 框架在极小的菜单栏弹出窗口中构建复杂且流畅的数据图表。

## 2. 核心监控技术的实现原理

阅读这些开源项目，你会发现他们获取系统数据并不是通过高级的 Swift API，而是通过调用底层的系统函数：

### CPU 与内存监控
*   **技术点**：通常使用 \`host_processor_info\` 或 \`host_statistics\` 等底层的 Mach 内核 API (属于 \`Darwin.Mach\` 模块) 来获取 CPU 核心的使用率和系统的物理/虚拟内存分配情况。这需要处理复杂的 C 语言结构体和指针转换。

### 网络流速监控
*   **技术点**：为了获取精确的实时网速，开源项目通常会读取底层的网络接口统计信息，或者使用 \`sysctl\` 命令查询路由表 (\`NET_RT_IFLIST2\`)，从而计算出 \`en0\` (Wi-Fi) 每秒收发了多少字节。

### 温度与风扇转速传感器 (SMC)
*   **技术点**：这是监控工具中最困难的部分，因为 Apple 没有公开访问系统管理控制器 (SMC) 的官方 API。
*   **学习点**：项目通常会包含一个名叫 \`SMCKit\` 或类似底层的封装库，通过向 IOKit (\`IOServiceOpen\`) 发送特定的魔数键值（如代表 CPU 温度的 \`TC0P\`）来读取主板上各个传感器的实时温度和风扇转速。由于这涉及到私有 API，通常这些 App 无法在 Mac App Store 上架，只能通过 GitHub 发布。

## 3. 性能优化

系统监控工具本身**绝对不能**成为消耗系统资源的元凶。

*   学习这些项目是如何利用 GCD (\`DispatchSourceTimer\`) 建立高效的低频轮询机制。
*   学习它们如何优化视图渲染（比如使用 Core Graphics 而不是繁重的 UI 控件绘制图表），以确保在每秒刷新 1 次数据时，监控软件本身的 CPU 占用率几乎为 0。
