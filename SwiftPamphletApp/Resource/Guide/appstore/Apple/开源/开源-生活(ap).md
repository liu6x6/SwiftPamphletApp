# Apple 平台生活方式与工具类开源项目

生活方式类 App（如记账、习惯打卡、倒数日、菜谱等）贴近用户日常，通常非常注重 UI 的精致度和交互的舒适感。研究这类开源项目是提升产品打磨能力的好方法。

## 1. 记账与个人财务

*   **MoneyHub / 各种记账 App Demo**
    *   **简介**：记账应用是极其考验本地数据存储架构的项目类型。
    *   **学习点**：
        *   深度运用 **Core Data** 或 **SwiftData**：处理一对多关系（账本 -> 账单）、多对多关系（账单 <-> 标签）。
        *   数据统计与聚合：如何高效地按月、按年进行账目汇总计算，并使用 \`SwiftCharts\` 渲染精美的饼图和柱状图。
        *   iCloud CloudKit 的无缝同步机制（让用户的账单在 iPhone 和 Mac 之间同步）。

## 2. 习惯养成与打卡 (Habit Tracker)

*   **Habitica (开源部分或类似项目)**
    *   **简介**：习惯追踪应用不仅需要数据管理，还需要深度的系统集成来“提醒”用户。
    *   **学习点**：
        *   **User Notifications (本地推送)**：如何按复杂的周期（比如每周一三五的早上8点）设置重复提醒。
        *   **交互式小组件 (Interactive Widgets)**：iOS 17 中，用户直接在桌面上点击打钩完成今天的习惯，而不需要打开 App。
        *   打卡热力图 (类似 GitHub 贡献图) 的 SwiftUI 自定义绘制。

## 3. 番茄钟与专注工具

*   **Pomodoro 相关的开源实现**
    *   **简介**：这类项目核心围绕着时间的精确计算和后台存活机制。
    *   **学习点**：
        *   **Live Activities (实时活动) & Dynamic Island (灵动岛)**：如何在锁屏和灵动岛上实时倒计时展示番茄钟的剩余时间。这是近两年 iOS 开发最热门的技术点！
        *   后台计时：当应用被切到后台或被杀死时，如何计算时间差并确保提醒准时触发。

## 4. 菜谱与购物清单

*   这类 App 通常展示了如何优雅地进行图文排版、以及如何通过 Share Extension (分享扩展) 从 Safari 浏览器中抓取网页上的菜谱数据并导入到自己的 App 中。
