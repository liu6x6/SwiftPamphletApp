# Apple 平台优秀的阅读类开源项目

阅读类应用（如 RSS 订阅、电子书阅读器、漫画阅读器）对排版的舒适度、夜间模式的支持以及大文件解析性能有着极高的要求。

## 1. RSS 与信息聚合阅读器

*   **NetNewsWire** (iOS / macOS)
    *   *之前多次提及，它是阅读类的绝对标杆。*
    *   **核心学习点**：
        *   多账号同步架构（如何同时支持 iCloud, Feedbin, Inoreader 的同步抽象层）。
        *   如何使用 \`WebKit\` (\`WKWebView\`) 渲染极其复杂的 HTML 文章内容，并注入自定义的 CSS 样式来实现完美的深色模式和排版。
        *   后台下载与解析（XML/JSON 提要的极速解析）。

## 2. EPUB / 电子书阅读器

开发一个电子书阅读器远比想象中复杂，因为 EPUB 本质上是一个被压缩的 HTML 网站。

*   **FolioReaderKit** (虽然较老，但依然是经典参考)
    *   **简介**：一个著名的开源 EPUB 解析和阅读框架。
    *   **学习点**：
        *   如何解压并解析 \`.epub\` 包中的 XML 索引文件。
        *   分页渲染机制：如何计算一段极长的 HTML 在手机屏幕上需要被分成多少页，并支持平滑的左右翻页（通常利用 \`UIPageViewController\` 结合横向滚动的 WebView）。
        *   文本高亮与划线标注：如何在 WebView 中用 JavaScript 获取用户选中的文本节点坐标，并将其保存到本地数据库。

## 3. PDF 阅读与批注

*   PDF 的渲染不依赖 WebKit，而是使用 Apple 底层的 \`PDFKit\` 框架。
*   **开源参考点**：许多开源的 PDF 库展示了如何使用 \`PDFView\` 加载大型文件，如何构建一个侧边栏来显示 PDF 的大纲（缩略图），以及最困难的——如何实现手写笔（Apple Pencil）在 PDF 上的流畅批注并将其保存回 PDF 文件中。

## 4. 漫画与图集阅读

*   **Kavita** 或其他开源漫画阅读器
    *   **简介**：专注于读取 CBZ、CBR 或 ZIP 压缩包内的图片。
    *   **学习点**：
        *   **内存管理**：几十页高清漫画同时解压会瞬间爆内存。学习如何实现只在内存中保留“当前页、上一页、下一页”的图片缓存池机制。
        *   支持从右到左 (RTL) 的日漫阅读模式布局。
        *   利用 \`UIScrollView\` 实现精细的图片缩放、双击放大和边缘回弹手势。
