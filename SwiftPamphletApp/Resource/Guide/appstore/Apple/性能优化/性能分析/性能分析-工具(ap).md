# iOS 性能分析工具图谱总览

要在 iOS 和 macOS 平台上做极其硬核的性能优化（解决极端的卡顿、耗电、内存 OOM、启动慢），单靠打印 \`print\` 日志是绝对不够的。
你必须在你的武器库中掌握不同维度的各种分析工具。以下是整个生态中最常用和最关键的工具图谱。

## 1. 官方静态与编译期工具

最好的性能优化是把 Bug 掐死在编译之前。

*   **Clang Static Analyzer (静态分析器)**：
    Xcode 自带的强大工具（快捷键 \`Cmd + Shift + B\` 触发 \`Analyze\`）。它在不运行代码的情况下，纯靠语法树推演，就能指出代码中潜在的逻辑死区、永远不会被释放的 CoreFoundation C指针（经典的内存泄漏源）、或者可能引发除以 0 的崩溃点。
*   **Thread Sanitizer (TSan / 线程消毒器)**：
    在 Xcode Scheme 设置 -> Diagnostics 中勾选。如果你的多线程代码存在数据竞争（Data Race），比如两个线程没有加锁同时修改一个字典，只要 App 一运行，TSan 会在发生竞争的**那一瞬间**极其精准地强行暂停 App，并把两个肇事线程的堆栈并排展示给你看！

## 2. 官方动态监控工具 (Apple 生态基石)

*   **Instruments**：
    这是性能优化的绝对王者。包含了 Time Profiler (看 CPU 和卡顿)、Leaks (抓循环引用)、Allocations (查内存爆炸)、Network (看请求阻塞) 等数十个极其底层的观测模板。（详见《Instruments.md》）。
*   **MetricKit**：
    iOS 13 引入。这是解决“线上用户手机发热卡顿，但开发在公司里死活复现不出来”的终极解法。它能在用户手机上静默收集过去 24 小时的真实电量消耗、挂起时间、Crash 频次，并打包发给你的服务器。（详见《MetricKit.md》）。
*   **Xcode Debug Gauges (调试仪表盘)**：
    平时插着线跑 App 时 Xcode 左侧的面板。能最直观地看到 CPU、内存和网络的实时波形图。

## 3. 第三方 APM 与 In-App 调试器

用于在测试阶段和生产环境下填补官方工具的盲区。

*   **FLEX**：
    最好的 In-App 界面、网络、沙盒探索工具。QA 测试的救星。
*   **腾讯 Matrix / GT**：
    可以直接在手机屏幕上悬浮显示 FPS、内存指标，支持离线记录卡顿堆栈。
*   **大厂自研 APM SDK (如字节 Slardar, 阿里 性能魔方)**：
    它们的核心是用 \`fishhook\` 或 \`Mach-O\` 级别的黑科技，强行替换系统的底层函数，实现**无痕**监控大盘用户的启动耗时、滑动流畅度。

## 4. 图形与渲染剖析工具

如果你在做游戏、3D 空间计算或极端的动画优化。

*   **Core Animation Instrument**：
    标记黄色的“离屏渲染 (Off-screen Rendering)”和红色的“像素混合重叠 (Color Blended Layers)”，用来打磨列表丝滑滚动的必需品。
*   **Metal Debugger (GPU 抓帧器)**：
    点击 Xcode 底部的一颗像照相机一样的按钮。它能把当前屏幕的这一帧画面极其变态地“拆解”开来，让你看到 GPU 是一步一步、从多边形顶点计算、到执行 Shader、最后涂上颜色的完整录像。这是排查诡异渲染发黑、贴图丢失的终极手段。

## 5. 底层与逆向分析工具

*   **Frida**：动态注入 JS 脚本，隔空拦截函数参数。（详见《Frida.md》）。
*   **Hopper Disassembler / IDA Pro**：把别人 App 的二进制机器码反编译成勉强能看懂的伪代码，用来学习竞品是怎么做架构优化的。
*   **Charles / Wireshark**：网络抓包老三样，排查网络请求过大导致解析卡顿的必备。
