# 战国四大名将

**时间**: 战国中后期

“战国四大名将”是指在中国战国时代后期，四位战功卓著、对历史进程产生了决定性影响的军事将领。他们分别是：

*   **白起** (秦国)
*   **王翦** (秦国)
*   **廉颇** (赵国)
*   **李牧** (赵国)

这四位将领，代表了战国时期军事思想和指挥艺术的最高水平。

## 1. 白起 (秦国) - “人屠”

*   **核心特点**: 善于打大规模的围歼战，作战极其凶狠，杀敌无数，被称为“人屠”。
*   **主要战绩**:
    *   **伊阙之战**: 大破韩、魏联军，斩首二十四万。
    *   **鄢郢之战**: 攻陷楚国都城郢都，迫使楚国迁都，从此楚国一蹶不振。
    *   **长平之战**: 这是白起军事生涯的巅峰之作。他诱敌深入，分割包围，最终坑杀赵国降卒四十万，使得赵国精锐尽失，再也无力与秦国抗衡。
*   **结局**: 功高震主，与秦昭襄王和丞相范雎产生矛盾，最终被赐死。
*   **评价**: 白起是战国时期最纯粹、最高效的“战争机器”。他一生指挥战役无数，未尝一败，其歼敌数量据估计超过百万，是整个战国时代歼敌最多的将领。他的军事才能毋庸置疑，但其残忍的杀戮，也使其在历史上留下了巨大的争议。

## 2. 王翦 (秦国) - “智将”

*   **核心特点**: 用兵老成持重，善于利用政治和心理战，不打无把握之仗。
*   **主要战绩**:
    *   **灭赵之战**: 在李牧被赵王冤杀后，王翦率军攻破邯郸，灭亡了赵国。
    *   **灭楚之战**: 这是王翦军事生涯的代表作。面对楚国倾国之力的六十万大军，他没有急于求战，而是率领六十万秦军，采取“坚壁不出、以逸待劳”的策略，与楚军对峙一年之久，最终在楚军松懈、准备东归之际，发动突袭，大破楚军，灭亡了楚国。
*   **结局**: 功成身退，得以善终。在灭楚之前，他故意向秦王嬴政请求大量的田产和赏赐，以แสดง自己并无政治野心，只求富贵，从而消除了秦王的猜忌。
*   **评价**: 王翦是一位极具政治智慧的将领。他不仅懂得如何打胜仗，更懂得如何在胜利之后保全自己。他与白起的不同结局，深刻地反映了“将在外，君命有所不受”的风险，以及在专制君主手下，功高震主者的生存智慧。

## 3. 廉颇 (赵国) - “老将”

*   **核心特点**: 经验丰富，勇猛善战，以防守见长。
*   **主要战绩**:
    *   **阏与之战后**: 曾率军攻取齐国，为赵国拓地。
    *   **长平之战 (前期)**: 面对秦国的进攻，他采取了正确的“坚壁清野、以守为战”的策略，成功地将秦军拖入了相持阶段，使其师老兵疲。如果不是被赵王临阵换将，长平之战的结局未可知。
*   **结局**: 在长平之战中被赵括替换，此后虽一度官复原职，但已不受信任。赵悼襄王继位后，他再次被解除兵权，最终被迫出奔魏国，后老死于楚国。晚年虽有报国之心，但已不被赵王所用，留下了“廉颇老矣，尚能饭否？”的千古慨叹。
*   **评价**: 廉颇是赵国在战国末期赖以支撑的军事长城。他的悲剧，不在于其军事才能，而在于君主的昏庸和猜忌。他是战国末期，山东六国面对强秦的步步紧逼，无力回天的悲剧英雄的缩影。

## 4. 李牧 (赵国) - “边将”

*   **核心特点**: 长期镇守赵国北疆，以防御和反击匈奴而闻名。其治军严明，善于运用骑兵和车兵协同作战。
*   **主要战绩**:
    *   **雁门之战**: 在对匈奴的作战中，他先是采取示弱、坚守不出的策略，麻痹对手，然后在匈奴大举入侵之际，利用预设的包围圈，以步、车、骑多兵种协同作战，大破匈奴十余万骑，使得匈奴十余年不敢南下。
    *   **肥之战**: 在秦国大举攻赵时，李牧从北疆被调回，在肥（今河北藁城西南）大破秦军，是战国末期山东六国对秦国取得的为数不多的一次重大胜利。
*   **结局**: 李牧的存在，是秦国灭赵道路上最大的障碍。秦国再次使用反间计，贿赂赵王宠臣郭开，诬陷李牧谋反。赵王不经查证，就派人取代并杀害了李牧。李牧死后仅三个月，赵国即被王翦所灭。
*   **评价**: 李牧被誉为“战国末年最后的名将”。他内能安邦，外能御敌，是赵国最后的军事支柱。他的死，与廉颇的被废一样，都直接宣告了赵国的灭亡。后人常将他和廉颇并称，感叹赵国的自毁长城。
